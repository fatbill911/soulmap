🎯 核心設計原則（已實現）
================================================================================

1. 模組化設計
   → 新增測驗不需修改頁面程式碼
   → 所有資料集中在 lib/ 管理

2. 資料邏輯分離
   → 頁面層：只負責 UI 渲染
   → 邏輯層：處理計算與轉換
   → 資料層：儲存內容與配置

3. 可擴充性
   → 易於新增測驗、星座內容、配對邏輯
   → 清晰的擴充指引與範例

4. 可維護性
   → TypeScript 型別安全
   → 清晰的檔案結構
   → 完整的程式碼註解

5. 使用者體驗
   → 直覺的操作流程
   → 美觀的視覺設計
   → 快速的載入速度

🚀 立即開始使用
================================================================================

1. 安裝依賴：
   cd soulmap
   npm install

2. 啟動開發：
   npm run dev

3. 開啟瀏覽器：
   http://localhost:3000

4. 建置部署：
   npm run build
   npm start

5. 部署到 Vercel：
   - 推送到 GitHub
   - 連結 Vercel
   - 自動部署完成

💡 關鍵檔案說明
================================================================================

最重要的 3 個檔案（擴充必看）：
  1. lib/quizzes.ts - 所有測驗資料與邏輯
  2. lib/astrology.ts - 所有星座資料與邏輯
  3. lib/match.ts - 所有配對分析邏輯

核心元件（可重用）：
  - components/QuizCard.tsx - 測驗卡片
  - components/QuestionStepper.tsx - 測驗步進器
  - components/ResultBlock.tsx - 結果顯示區塊

主要頁面：
  - app/page.tsx - 首頁
  - app/quiz/[slug]/page.tsx - 動態測驗頁
  - app/result/[slug]/page.tsx - 動態結果頁
  - app/astro/[sign]/page.tsx - 動態星座頁

================================================================================
⚠️ 重要提醒
================================================================================

1. 新增測驗時：
   ✓ 只需編輯 lib/quizzes.ts
   ✗ 不要直接修改頁面檔案

2. 更新星座時：
   ✓ 只需編輯 lib/astrology.ts
   ✗ 不要把資料寫在頁面裡

3. 調整配對時：
   ✓ 只需編輯 lib/match.ts
   ✗ 不要在元件內寫計算邏輯

4. 擴充功能時：
   ✓ 遵循現有的資料邏輯分離原則
   ✗ 不要為了方便而打破架構
