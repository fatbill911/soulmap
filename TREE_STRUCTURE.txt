🔄 資料流向示意
================================================================================

使用者操作              →  頁面元件              →  邏輯層              →  資料層
─────────────────────────────────────────────────────────────────────────
點擊「開始測驗」        →  app/quiz/[slug]      →  getQuizBySlug()     →  quizzes[]
選擇答案並提交          →  QuestionStepper      →  scoreToResult()     →  維度計分
查看測驗結果            →  app/result/[slug]    →  QuizResult          →  ResultBlock

點擊「星座」            →  app/astro            →  zodiacSigns         →  12星座資料
點擊「牡羊座」          →  app/astro/[sign]     →  getSignData()       →  今日/週/月

填寫配對表單            →  app/match            →  analyzeMatch()      →  相性計算
                                                   ├─ elementCompatibility
                                                   └─ specificPairings

================================================================================
🎯 核心設計模式
================================================================================

1. 資料層 (Data Layer)
   位置：lib/*.ts
   職責：儲存測驗題目、星座內容、配對邏輯
   格式：TypeScript 物件與陣列（可移到 JSON）

2. 邏輯層 (Logic Layer)
   位置：lib/*.ts 的函式
   職責：計算分數、過濾資料、轉換格式
   原則：純函式、可測試、可重用

3. 元件層 (Component Layer)
   位置：components/*.tsx
   職責：UI 呈現、使用者互動
   原則：可重用、接收 props、不含業務邏輯

4. 頁面層 (Page Layer)
   位置：app/**/page.tsx
   職責：組合元件、呼叫邏輯函式、路由處理
   原則：輕薄、只做協調工作

⚡ 關鍵擴充點
================================================================================

想新增測驗？
  → 只需編輯 lib/quizzes.ts
  → 加入新的 Quiz 物件到 quizzes 陣列
  → 自動出現在所有相關頁面

想更新星座？
  → 只需編輯 lib/astrology.ts
  → 修改對應星座的 today/week/month
  → 自動反映在星座頁面

想調整配對？
  → 只需編輯 lib/match.ts
  → 修改 specificPairings 或 elementCompatibility
  → 自動更新配對結果

想新增頁面？
  → 在 app/ 下新增資料夾與 page.tsx
  → Next.js 自動建立路由
  → 在 SiteHeader 加上導覽連結
